# ACF Paving WordPress Theme

[English](README.md) | Deutsch

## Überblick

ACF Paving WordPress Theme ist eine bereinigte Demo eines individuellen WordPress-Themes mit Fokus auf ACF/Flexible Content, wiederverwendbare PHP-Templates, responsives Frontend, Kalkulatoren, Bewertungen, Portfolio-Bereiche, FAQ/SEO-Blöcke und redaktionsfreundliche Strukturen.

Dieses Repository ist eine bereinigte Portfolio-Version. Kundenspezifische Daten, Zugangsdaten, produktive Endpunkte und proprietäre Inhalte wurden entfernt oder durch Demo-Werte ersetzt.

## Meine Rolle

Ich habe Theme-Architektur, ACF-Feldgruppen, wiederverwendbare Sektionstemplates, responsives Frontend-Verhalten, Kalkulatoren, Formularabläufe und SEO-orientierte Content-Blöcke umgesetzt.

## Hauptfunktionen

- Flexible Seitenbereiche auf ACF-Basis.
- Wiederverwendbare PHP-Template-Part-Architektur.
- Kalkulator-UI und Frontend-Interaktionslogik.
- Portfolio- und Review-Templates.
- Formularmuster mit Demo-Platzhaltern.
- FAQ/SEO-Strukturen für Service-Landingpages.
- Responsives CSS für Figma-to-WordPress-nahe Umsetzung.

## Technologie-Stack

WordPress, PHP, ACF, JavaScript, AJAX, CSS, responsives Frontend, SEO/FAQ-Strukturen.

## Was dieses Repository zeigt

- Praxisnahe Entwicklung eines individuellen WordPress-Themes für Service-Websites.
- Editorfreundliche Backend-Struktur mit ACF JSON.
- Wiederverwendbare Rendering-Muster über mehrere Landingpage-Templates.
- Frontend-Sorgfalt bei Responsiveness, Kalkulatoren, Formularen und strukturiertem SEO-Content.

## Architektur / Implementation

- `functions.php` und `inc/` registrieren Theme-Verhalten, Helper, Post Types und Formlogik.
- `acf/` enthält bereinigte Feldgruppen.
- `template-parts/flexible/` enthält wiederverwendbare Sektionen.
- `assets/js/theme.js` enthält Frontend-Interaktionen.
- `assets/css/theme.css` enthält responsives Sektionsstyling.

## Setup

1. Theme nach `wp-content/themes/acf-paving-wordpress-theme` kopieren.
2. ACF Pro lokal installieren und aktivieren.
3. Theme aktivieren.
4. ACF JSON aus `acf/` synchronisieren.
5. Synthetische Demo-Seiten, Reviews, Portfolio-Einträge und Medien anlegen.
